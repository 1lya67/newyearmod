# New Year Winter (Fabric, Minecraft 1.21.11)

- снег идёт везде, быстро ложится слоем и убирает траву, папоротники и сухие кусты рядом с игроком;
- вода не замерзает в пустыне, саванне, болоте и мангровом болоте (и в реках рядом с ними);
- зимнее небо (ледяной день, розовый закат, тёмно-синяя ночь с яркими звёздами);
- листва всех деревьев с новогодними шариками, 4 варианта текстуры;
- предмет "Новогодняя ёлка" (креатив, вкладка "Функциональные блоки"; крафт: саженец ели + красный, синий и жёлтый красители);
- у каждой профессии жителей свой новогодний наряд.

Сборка: `gradle build` -> `build/libs/newyear-1.2.0.jar`.
