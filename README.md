# New Year Winter (Fabric, Minecraft 1.21.11)

- везде идёт снег (даже в пустыне), вода замерзает, снег ложится слоями;
- погода в Верхнем мире всегда "осадки" и без грозы;
- на всех деревьях (мир + саженцы) висят разноцветные светящиеся шары.

## Сборка
1. Java 21+.
2. Положи рядом `gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`
   из любого шаблона Fabric (https://fabricmc.net/develop/template) либо выполни `gradle wrapper`.
3. `./gradlew build`  ->  `build/libs/newyear-1.0.0.jar` в папку mods.
   Тест: `./gradlew runClient`.
