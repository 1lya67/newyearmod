# New Year Winter (Fabric, Minecraft 1.21.11)

- снег идёт везде (даже в пустыне), погода всегда "осадки" без грозы;
- снег ложится слоем и убирает траву, папоротники и сухие кусты рядом с игроком;
- зимнее небо: ледяной голубой день, розовый рассвет/закат, тёмно-синяя ночь с яркими звёздами;
- листва всех деревьев (дуб, ель, берёза, джунгли, акация, тёмный дуб, мангровое, вишня, бледный дуб)
  заменена на текстуру с новогодними шариками.

Сборка: `gradle build` (см. .github/workflows на GitHub) -> `build/libs/newyear-1.1.0.jar`.
