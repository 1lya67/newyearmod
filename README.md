# New Year Winter (Fabric, Minecraft 1.21.11)

Возможности: вечный снегопад, снег убирает траву/кусты/цветы, снег после поломки возвращается через 10-15 минут,
вода не замерзает в пустыне/саванне/болотах, зимнее небо, листва с маленькими шариками (4 варианта),
ёлки (1 и 2 блока), 4 новогодних фонарика, иней на стёклах, наряды жителей.

Текстуры, модели и рецепты генерирует скрипт `tools/gen_assets.py` (в GitHub Actions он запускается перед сборкой).
Локально: `python tools/gen_assets.py`, затем `gradle build` -> `build/libs/newyear-1.3.0.jar`.
